**Repository:** [github.com/benahalkar/loading_and_finetuning_LLMs](https://github.com/benahalkar/loading_and_finetuning_LLMs)

This project aims to load an LLM (Llama-7B) and a dataset and fine-tune it in a low computing environment. The free tier of Google Colab provides one T4 (16GB) GPU and 11GB of CPU RAM.

This demonstrates how to use LoRA and quantization to fine-tune the model.

Technologies used: HuggingFace, Jupyter.
